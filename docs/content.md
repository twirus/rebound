# Каталог контента

Стартовый набор контента. Числа — ориентиры для первой версии, финальные значения подбираются через `npm run balance`. Новый контент добавляется по правилам в конце файла.

Обозначения: **Нагр.** — нагрузка камня (см. `design.md` §5), **Этап** — этап `roadmap.md`, на котором появляется.

---

## 1. Формы

| id | Название | Поведение | Ресурс | Теги | Этап |
|---|---|---|---|---|---|
| `shape:circle` | Круг | Стабильные предсказуемые отскоки. Лучшая база для схем, которым нужна стабильность. | Импульс | удар | 1 |
| `shape:triangle` | Треугольник | Удар в зону у вершины — «угловой удар»: шарик раскалывается, клон живёт 4 с. | Импульс | угол, раскол | 3 |
| `shape:square` | Квадрат | Одна грань — портал, сменяется по часовой каждые 8 ударов. Шарик выходит с противоположной грани или, при наличии связи, в соседнюю арену. | Импульс | портал, связь | 3 |
| `shape:hexagon` | Шестиугольник | Грани шести цветов. Шарик принимает цвет грани. Серия из 3+ ударов в грани одного цвета — комбо. | Спектр | цвет | 3 |
| `shape:rings` | Кольца | 3–12 вложенных вращающихся колец со щелями. Пролёт сквозь щель разбивает кольцо, кольца медленно отрастают. Побег из внешнего — событие «Побег». | Осколки | разрушение, побег | 3 |
| `shape:mosaic` | Мозаика | Стена из плиток с прочностью. Разбитая плитка срабатывает своим эффектом (тип плитки — из пула по сиду), стена отрастает. | Осколки | разрушение | 3 |
| `shape:spiral` | Спираль | Гравитация закручивает шарики к центру. Чем ближе к центру, тем быстрее время арены. Достигший центра шарик выбрасывается к краю. | Хронос | время, гравитация | 3 |
| `shape:pulsar` | Пульсар | Форма дышит в такт (BPM из настроек арены). Удар во время расширения подбрасывает. Удары в сильную долю дают Резонанс. | Резонанс | ритм | 6 |
| `shape:star` | Звезда | Шарик в луче застревает и заряжается, потом вылетает с накопленной скоростью. Два шарика в одном луче сливаются. | Масса | заряд, слияние | 3 |
| `shape:horizon` | Горизонт | Без внешней стены почти нет отскоков — в центре гравитационная точка, шарики ходят по орбитам и сливаются. Даёт понемногу все ресурсы. Поздняя форма. | Масса + все | гравитация, слияние | 8 |

У каждой формы — группа улучшений (3–6 строк в дереве): размер, скорость вращения, особые параметры (число колец, прочность плиток, BPM и т. п.). Улучшения меняют поведение заметно глазу.

| `ball:void` | Пустой | касанием снимает статусы и гасит эффекты — контроль хаоса | сам не приносит ресурсов | контроль |

## 7. Связи между аренами

Ставятся на ребро сетки между соседними аренами.

| id | Название | Что делает |
|---|---|---|
| `link:portal` | Портал | шарик, сбежавший или вошедший в портал квадрата, появляется в соседней арене |
| `link:channel` | Канал | 10% ресурсов арены A превращаются в заряд схем арены B (B срабатывает чаще) |
| `link:sync` | Синхрон | арены вращаются в такт; совпавшие удары дают Резонанс |
| `link:conveyor` | Конвейер | побег из A — вход в B; цепочка арен даёт растущий множитель за каждый пройденный этап |
| `link:sacrifice` | Жертва | шарик, исчезнувший в A, усиливает случайный шарик в B |
| `link:echo` | Отголосок | событие выбранного типа в A срабатывает и в B на 30% силы |

## 9. Эволюции (примеры)

Принцип: альтернатива — другое поведение. Claude Code придумывает эволюции для остальных камней по тому же принципу и показывает список пользователю перед внедрением.

| Камень | Альтернатива |
|---|---|
| Раскол | **Тройной раскол**: 3 клона, живут 1,5 с. **Наследственный раскол**: 1 клон, живёт до первого столкновения, наследует статусы. |
| Взрыв | **Имплозия**: стягивает шарики к точке вместо толчка. |
| Телепорт | **Скачок**: телепорт по направлению движения на фиксированную дальность. |
| Временная зона | **Стоп-кадр**: зона полностью останавливает время на 1 с. |
| Ткач | **Паутина**: нити становятся упругими стенками. |
| Энтропия | **Негэнтропия**: доход растёт от порядка — чем ровнее движутся шарики, тем больше. |
| Удар о стену | **Удар о ту же стену**: срабатывает только при двух ударах подряд в один отрезок, ×4. |
| Столкновение | **Лобовое**: только если скорости почти противоположны, ×3. |

## 11. Синергии Кодекса (примеры, всего ~40)

| Сочетание | Что происходит |
|---|---|
| Звезда + Ткач | нити из лучей звезды образуют созвездие; контур в форме звезды ×5 |
| Кольца + Призрак + Побег | призраки разбивают кольцо на выходе — «чистый побег», двойные Осколки |
| Спираль + Песочные часы | время в центре спирали течёт назад: шарики ненадолго возвращаются по своему пути |
| Шестиугольник + Хамелеон + Серия | шарик подстраивает цвет к грани заранее — бесконечные серии на 10 с |
| Пульсар + Стая | стая «дышит» вместе с формой, удары синхронизируются — Резонанс ×3 |
| Огненный + Ледяной в одной арене | столкновение горячего и ледяного даёт пар — облако, замедляющее всё внутри и дающее Хронос |
| Горизонт + Голод | шарики поглощают друг друга до одного гиганта — «звезда» с собственной гравитацией |
| Квадрат + Портал + Конвейер (3 арены) | замкнутая петля: шарик, прошедший круг, становится «бывалым» и даёт ×3 всего |
| Эгоист + Фокус + Хрупкость | одинокий шарик раскалывается не на клонов, а на эхо-тени, которые не нарушают Эгоиста |
| Мозаика + Ржавчина | плитки ржавеют и при разрушении дают свой эффект дважды |

Синергии проверяются по условиям из данных (`content/synergies.ts`), поведение — модуль в `sim/synergies/`.

## Правила добавления нового контента

Перед добавлением камня, формы, шарика или закона проверь:

1. **Меняет ли он поведение или картинку?** Если только цифру — это строка улучшения, а не новый контент.
2. **Есть ли минус?** У поддержек, законов и шариков — обязательно.
3. **Создаёт ли он выбор?** Есть ли сборка, где он лучший, и сборка, где он плох?
4. **Не делает ли он другой камень бесполезным?** Если да — переделай один из них.
5. **Теги и нагрузка** указаны, тексты есть в `ru.json` и `en.json`.
6. **Не повторяет ли он уже существующий** под другим названием?

Если не проходит — не добавляй.
