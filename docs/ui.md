# Интерфейс и визуальный стиль

Референс дерева прокачки: `docs/ui-reference.webp`. Берём из него **структуру и характер**: тёмный фон, строгие прямоугольные карточки, тёплый янтарный акцент, маленькие подписи капсом, статусы словами, колонки «шагов», левая панель категорий со счётчиками, правая панель деталей, нижняя строка подсказок. Иконки инструментов из референса не копируем — у нас свои.

## 1. Характер

- Строго, спокойно, по-инженерному. Похоже на хорошо сделанный инструмент, а не на мобильную игру.
- Арена — единственное «живое» место на экране. Интерфейс вокруг тихий.
- **Запрещено** (это и есть «ИИ-слоп»): неон и свечение, градиенты, стекло и размытие фона, скругления больше 2 px, тени-подложки, эмодзи, фиолетово-синие «технологичные» палитры, иконки-кружочки в пастельных плашках, бодрые тексты («Отлично! 🎉»), анимации ради анимаций.
- Тексты короткие и сухие: «Открывает треугольник. Удар в угол раскалывает шарик.» Цифры конкретные.

## 2. Цвета

Все цвета — CSS-переменные в одном файле (`src/ui/theme.css`). Тема одна — тёмная.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0a0a0a` | фон экрана, фон арены |
| `--panel` | `#141414` | карточки, панели |
| `--panel-raised` | `#1b1b1a` | выбранная карточка, шапки групп |
| `--line` | `#2a2a28` | рамки, разделители, неактивные линии дерева |
| `--text` | `#e8e6e1` | основной текст |
| `--text-dim` | `#8a8780` | подписи, вторичный текст |
| `--text-mute` | `#55534e` | заблокированное |
| `--accent` | `#e0a040` | янтарь: категории, купленное, активные линии, выбор |
| `--ok` | `#9ccc65` | цена, на которую хватает ресурсов |
| `--warn` | `#c9694a` | редкие предупреждения (сброс, коллапс энтропии) |

Ресурсы — приглушённые цвета, по одному на ресурс: Импульс `#e8e6e1`, Осколки `#7fb2c9`, Масса `#c98f6a`, Спектр `#b59ad1`, Хронос `#d4c36a`, Резонанс `#7fc9a3`. Ветки дерева в левой панели получают такие же приглушённые цвета полоски, как в референсе.

## 3. Шрифты

- **Barlow** (400, 500, 600) — текст и числа. **Barlow Semi Condensed** (500, 600) — подписи капсом и заголовки карточек.
- Числа — `font-variant-numeric: tabular-nums`, чтобы не прыгали.
- Подписи-категории: капс, 11–12 px, `letter-spacing: 0.06em`, цвет `--accent`.
- Шкала: 11 / 13 / 15 / 18 / 24 px. Других размеров нет.

## 4. Главный экран

```
┌──────────────────────────────────────────────────────────┐
│ REBOUND     Импульс 12 345  Осколки 820  …        ⚙  ДЕРЕВО│  ← верхняя строка
├──────────────────────────────────────────┬───────────────┤
│                                          │ АРЕНА 1        │
│                                          │ Круг · Поток   │
│                 АРЕНА                    │ ── ЗАКОН ──    │
│                                          │ ── СХЕМЫ ──    │
│                                          │ нагрузка 7/10  │
├──────────────────────────────────────────┴───────────────┤
│ +18,4 Импульса/с · тап — толчок · T — дерево · Tab — арены │  ← нижняя строка
└──────────────────────────────────────────────────────────┘
```

- **Верхняя строка:** название, ресурсы (только открытые), справа — настройки и кнопка дерева.
- **Арена** — по центру, занимает максимум места.
- **Правая панель** (360 px) — сборка выбранной арены: форма, шарик, режим, закон, схемы со слотами, нагрузка. Сворачивается.
- **Нижняя строка** — доход в секунду и подсказки по управлению, как в референсе.
- С несколькими аренами: кнопка «Обзор» показывает все арены сеткой 3×2.

## 5. Арена

- Фон `--bg`. Стены — тонкие линии 1,5 px, цвет `--text` с прозрачностью 0,85. Без свечения.
- Шарики — сплошные круги приглушённых цветов, без обводки и бликов.
- След шарика — короткий, тонкий, гаснет за 0,3 с (отключается в настройках).
- Частицы при разрушении — несколько маленьких квадратиков, разлетаются и гаснут. Мало, но приятно.
- Подсветка события — короткая вспышка цвета линии (100 мс), не свечение.
- Всплывающие числа ресурсов — по умолчанию выключены (визуальный шум), включаются в настройках.
- Плавность важнее эффектов: стабильные 60 FPS, сглаживание движения между тиками симуляции (интерполяция).

## 6. Дерево прокачки (как в референсе)

Открывается на весь экран поверх игры (арена продолжает идти).

### Раскладка

- **Колонки по шагам:** заголовки сверху — «СТАРТ», «1 ШАГ», «2 ШАГА», … Шаг узла = длина самой длинной цепочки зависимостей от корня ветки.
- **Ветки — горизонтальные полосы** друг под другом, у каждой полосы — тонкая цветная линия слева.
- **Раскладка автоматическая** по данным: узлы внутри колонки сортируются так, чтобы линии меньше пересекались (простая эвристика барицентров). Ручных координат в данных нет.
- **Линии связей:** ортогональные, с изломом под прямым углом, 2 px. Путь к купленным узлам — `--accent`, остальные — `--line`.

### Карточка-открытие (крупная)

```
┌──────────────────────────────┐
│ [иконка]  ГЕОМЕТРИЯ           │ ← ветка, капс, --accent
│           Треугольник         │ ← название, 18 px
│                               │
│ ГОТОВО              ОТКРЫТО   │ ← или цена и уровень
└──────────────────────────────┘
```

- Размер ~300×120 px. Левая граница 3 px — цвет статуса.
- Состояния:
  - **Скрыто** — силуэт, название «???», цена не видна, прозрачность 0,35.
  - **Заблокировано** — видно, но зависимости не куплены; текст `--text-mute`, слово «ЗАКРЫТО».
  - **Доступно, не хватает** — цена `--text-dim`.
  - **Доступно, хватает** — цена `--ok`, рамка `--ok` с прозрачностью 0,6 (как «Broom $10.00» в референсе).
  - **Куплено** — рамка `--accent`, внизу «ГОТОВО» и «ОТКРЫТО».
  - **Выбрано** — рамка `--accent` 2 px.

### Группа улучшений (мелкая)

Шапка капсом «УЛУЧШЕНИЯ ТРЕУГОЛЬНИКА», ниже строки: иконка, название, цена, уровень `0/5`. Купленная до конца строка — «ГОТОВО 5/5».

### Панели

- **Левая панель — ветки:** название ветки капсом, под ним «19 из 46 куплено · 8 доступно», цветная вертикальная полоса. Клик — прокрутка к ветке.
- **Правая панель — детали узла:** крупная иконка, ветка, название, статус, описание (1–3 строки), что именно открывает, цена по ресурсам (каждый своим цветом), кнопка покупки внизу. Если всё куплено — «ПОЛНОСТЬЮ КУПЛЕНО».
- **Верх:** заголовок «ДЕРЕВО», поле «поиск по дереву», справа — ресурсы.
- **Низ:** «94 из 357 уровней куплено · колесо — масштаб, клик — карточка, двойной клик — купить, правая кнопка — перемещение».

### Управление

- ПК: колесо — масштаб к курсору, перетаскивание — перемещение, клик — выбрать, двойной клик — купить, `/` — поиск, `Esc` или `T` — закрыть.
- Телефон: щипок — масштаб, палец — перемещение, тап — выбрать (детали выезжают снизу), кнопка «Купить» в панели деталей. Двойной тап не используется.
- Поиск подсвечивает совпадения и гасит остальное.
- Камера дерева запоминается между открытиями.

### Иконки

Свои, простые, линейные, рисуются из данных: форма — её контур, шарик — круг с особенностью (снежинка-штрих, пламя-штрих…), камни — геометрический знак по типу (событие — ромб, эффект — круг, поддержка — квадрат, закон — шестиугольник, связь — две точки с линией). Цвет иконки — `--text-dim`, у купленных — `--text`. Никаких картинок-файлов и эмодзи.

## 7. Сборка арены (правая панель)

```
АРЕНА 2                          нагрузка 14/20
Шестиугольник · Хамелеон · Ритм

ЗАКОН
[ Стая                          3 ]

СХЕМЫ
1  [Серия] → [Перекраска]  + [Эхо] [Только красные]   7
2  [Столкновение] → [ … ]  + [ пусто ]               2
3  ЗАКРЫТО
```

- Слоты — прямоугольники с тонкой рамкой; пустой — пунктир.
- Клик по слоту — список подходящих камней с фильтром по тегам. Камень, стоящий в другой арене, показан с пометкой «в арене 1» — можно переставить одним кликом.
- Нагрузка: число и тонкая полоса; при превышении камень не ставится и коротко объясняется почему.
- Под схемой — маленькая строка статистики: срабатываний в минуту и доход.

## 8. Телефон

- Вертикально: арена сверху (квадрат по ширине экрана), панель сборки снизу с прокруткой. Ресурсы — в одну строку сверху с горизонтальной прокруткой.
- Горизонтально — как ПК, панель сворачивается в край.
- Размер касаемых элементов не меньше 40 px.
- Всё проверяется на ширине 360 px.

## 9. Окна и сообщения

- Окно — панель `--panel` с рамкой `--line`, без затемнения всего экрана (кроме сброса).
- Уведомления (открыта синергия, эволюция доступна) — строка в правом нижнем углу на 4 с, капс-подпись цвета `--accent` + одна строка текста.
- Нет всплывающих окон, которые блокируют игру, кроме подтверждения сброса и финальной сцены.

## 10. Движение

- Переходы интерфейса — 120–180 мс, `ease-out`. Ничего не прыгает и не пружинит.
- Покупка узла: короткая вспышка рамки и линия связи «заливается» янтарём слева направо за 300 мс.
- При «уменьшении движения» — всё мгновенно, следы шариков выключены.
