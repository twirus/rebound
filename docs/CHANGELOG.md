# Changelog

## Этап 3. Формы, шарики, ресурсы (в работе)

### Часть 1: Кольца

- Формы в симуляции — модули `sim/shapes/` по `kind` (`circle`, `rings`), с общим интерфейсом: шаг стен, столкновение шарика, зона появления, хэш. Круг переехал туда без изменения результата (эталонный хэш тот же).
- Детерминированные `detSin`/`detCos` в `core/detMath.ts` (только `+ − × ÷`), чтобы вращать стены одинаково на всех устройствах.
- Форма «Кольца»: 4 вложенных кольца, у каждого щель, соседние вращаются в разные стороны. Пролёт сквозь щель разбивает кольцо насовсем (осколки разлетаются, звучит нота). Разбить внешнее кольцо — «Побег»; шарик улетает, и начинается новый раунд: все кольца на месте, шарик в центре.
- След за шариками: короткий, тонкий, гаснет за 0,3 с, цвета шарика; выключен при «уменьшении движения».
- Ресурс Осколки: +1 за кольцо, +5 за Побег. Ресурсы в верхней и нижней строке видны, только когда открыты.
- Панель «Арена» справа (на телефоне — под ареной): выбор формы и шарика, выбор сохраняется.
- Ветка «Геометрия»: «Кольца» (2 500 Импульса) и «Улучшения колец» за Осколки: ещё кольцо (до 12), шире щели, медленнее вращение (щели дольше идут ровно), больше Осколков за кольцо и за Побег.
- По отзыву: 34 кольца почти вплотную (шаг 6 — уже шарика: разбитые кольца до конца раунда не возвращаются, так что шарик всегда внутри самого внутреннего целого кольца), внешний радиус прежний; улучшение даёт +1 кольцо наружу; линии колец чуть толще. Веер расходится вдвое медленнее (`speedStep` 0,04). В Кольцах всегда один шарик (¾ обычного размера) (`maxBalls`, `ballScale` в данных формы) — остальные ждут в Круге. Кольца не отрастают по одному — только новым раундом после Побега. Все щели стартуют в одной точке и крутятся в одну сторону с разной скоростью — расходятся веером. Каждое разбитое кольцо разворачивает вращение всех колец: щели сходятся обратно в стартовой точке и расходятся в другую сторону.
- Темп (бот 1 минуту из 3 сидит в Кольцах): Кольца на ~7-й минуте, их улучшения раз в 0,5–1 мин до ~37-й минуты. Если сидеть только в Кольцах, Импульс почти не идёт — выгодно переключаться.

## Этап 2. Дерево целиком (как система)

- Модель узла: вид (открытие — крупная карточка, улучшение — строка в группе, ключевой узел — карточка с ромбом), иконка из данных, зависимости «все» или «любое из», дополнительные условия (стат не меньше N, куплено N уровней, «будущая версия»), цена в нескольких ресурсах. Группы улучшений — отдельная запись `treeGroups`.
- Контент разнесён: `content/tree/basis.ts` (Основа), `content/tree/future.ts` (силуэты), `content/tree/index.ts`.
- «Основа» целиком: 14 узлов, 73 уровня, 3 группы (толчок, отдача, автотолчок). Новое: Дальность толчка, Сила автотолчка, Эхо толчка (ключ, открывается любым из двух узлов), Усилитель (+25% Импульса, условие — 15 шариков).
- 7 будущих веток силуэтами (Геометрия, Материя, Механизм, Связи, Время, Гармония, Сингулярность): 21 узел, всего в дереве 35 узлов и 112 уровней.
- Раскладка: группы — единый блок, карточки разной высоты, барицентры по центрам, полосы веток с цветной линией слева. Линия горит янтарём, когда куплены оба её конца.
- Камера: колесо — масштаб к курсору, перетаскивание (и правой кнопкой), щипок двумя пальцами; положение запоминается между открытиями и перезагрузками.
- Поиск (`/`): совпадения видны, остальное гаснет; `Enter` — к первому совпадению, `Esc` — очистить.
- Левая панель: клик по ветке переносит к ней. Панель деталей: иконка, условия с отметкой выполнено/нет, «Нужно» / «Нужно любое из», «Открывает: …», цены по ресурсам их цветом.
- Телефон: детали выезжают снизу только при выборе карточки, кнопка «Скрыть»; подсказки для касаний.
- Темп (`npm run pace`): почти вся «Основа» (72 из 73 уровней) за ~45 мин, ожидания до ~2 мин, последние уровни Усилителя дольше.

## Этап 1. Ядро: залипательный круг

- Физика: столкновения шариков (пространственная сетка, без аллокаций в цикле), подшаги против туннелирования, предел скорости 1400, «пружинные» стены (минимальная скорость отскока).
- Симуляция выдаёт события за тик (удар о стену, столкновение, толчок); толчки — входы в очередь, применяются в начале тика (повторяемо).
- Экономика в `game/`: статы из узлов (`content/tree.ts` → `effects`), цены `base × growth^level`, лимиты статов (шарики ≤ лимита), доход в секунду (среднее за 5 с).
- Дерево «Основа», 10 узлов, 61 уровень: Шарик, Отдача, Сила толчка, Пружинные стены, Столкновения, Перезарядка, Размер круга, Лимит шариков, Автотолчок, Частота автотолчка.
- Тап / клик — толчок от точки касания, перезарядка 2 с, кольцо-вспышка. Автотолчок снизу круга.
- Звук: треугольная волна через фильтр, минорная пентатоника по углу удара, громкость от силы, лимит 24 голоса и 4 новых за кадр, компрессор. Кнопка «Звук вкл/выкл» (настройка сохраняется).
- Сохранение в `localStorage`: каждые 15 с, при скрытии вкладки и закрытии; версия схемы и цепочка миграций; повреждённое сохранение откладывается в `rebound.save.broken`.
- Экран дерева: автораскладка по шагам (барицентры), ортогональные линии, состояния карточек (скрыто/закрыто/лимит/доступно/куплено/выбрано), левая панель веток, правая панель деталей с «было → станет», покупка кнопкой или двойным кликом, `T`/`Esc`. На телефоне детали снизу.
- `npm run pace` — бот покупает самое дешёвое: первая покупка ~20 с, в начале каждые 10–30 с, всё дерево ~35–40 мин.

## Этап 0. Каркас

- Проект: Vite + TypeScript (strict) + Preact + signals, ESLint, Prettier, Vitest.
- Структура папок по `CLAUDE.md`; линтер запрещает в `sim/` `Math.random`, `Date`, DOM и неточные функции (`Math.sin` и т. п.), а в `content/` — функции и классы.
- Ядро: RNG с сидом (mulberry32), хэш состояния, фиксированный шаг 1/120 с, игровой цикл с интерполяцией отрисовки.
- Симуляция-заглушка: круг и один шарик под гравитацией с упругим отскоком.
- Экран: верхняя строка (название, Импульс), арена на canvas с учётом `devicePixelRatio`, нижняя строка (доход в секунду). Тема `theme.css`, шрифт Roboto Condensed (с кириллицей; Barlow заменён — в нём нет русских букв).
- При скрытой вкладке симуляция и отрисовка стоят.
- Контент как данные: `types.ts`, ресурс Импульс, форма Круг, шарик Обычный; i18n `ru.json` / `en.json`.
- Тесты: детерминизм (10 000 тиков → эталонный хэш), валидатор контента, RNG, форматирование чисел, физика круга.
- GitHub Actions: проверки на каждый пуш, деплой на GitHub Pages из `main`.
